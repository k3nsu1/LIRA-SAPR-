# 0003 — Постобработка плит — модуль внутри сервера, отдельный от ЛИРЫ

- Date: 2026-11-03
- Status: accepted
- Approved by: owner

## Context

Во второй версии сервер считает прогибы плит относительно опор, рисует изополя
прогибов и мозаики армирования, собирает отчёты Word/PDF и DXF с зонами доборов
([продукт](../PRODUCT.md), раздел «Вторая версия»). Это инженерная логика поверх
результатов: в ЛИРЕ 2024 её нет в API (изополя и мозаики со шкалами — только в окне
ЛИРЫ), а правила счёта должны быть одинаковыми в каждом задании. Нужно решить, где эта
логика живёт.

## Options

### Модуль внутри сервера на чистом Python, без ЛИРЫ — chosen

- Advantages: агенту — один вызов с короткой сводкой, сотни тысяч значений через агента
  не идут; данные из ЛИРЫ читаются один раз существующими адаптерами; модуль получает
  массивы (узлы, пластины, опоры, перемещения, армирование) и тестируется без ЛИРЫ на
  задачах с известным ответом; в архитектуре уже есть сервисы без ЛИРЫ (копии,
  обработка результатов) — схема частей не меняется.
- Limitations: сервер перестаёт быть только мостом к ЛИРЕ. Потолок — когда те же проверки
  понадобятся для другой программы (SCAD, ЛИРА с другим API) или для результатов вне
  ЛИРЫ.
- Cost and effort: средние — алгоритм перебора линий, картинки, отчёты.
- Changing it later: легко — модуль не зависит от ЛИРЫ и выносится в отдельный пакет
  почти без переделок.

### Отдельный пакет или MCP-сервер «инженерные проверки»

- Advantages: сервер ЛИРЫ остаётся тонким; проверки годятся для любой расчётной
  программы.
- Limitations: два компонента в установке и сопровождении; агент связывает выгрузку и
  расчёт через файлы; нужны новые инструменты выгрузки геометрии.
- Cost and effort: выше, чем у модуля.
- Changing it later: средне.

### Агент считает сам в каждом задании

- Advantages: ничего не разрабатываем.
- Limitations: алгоритм пишется заново каждый раз и не проверен тестами; два задания
  могут посчитать по-разному; большие объёмы данных идут через агента.
- Cost and effort: нулевые сейчас, высокие в ошибках.
- Changing it later: легко, но нечего сохранять.

## Decision

Модуль постобработки в `src/lira_sapr_mcp/postprocessing/` на чистом Python: прогибы
относительно опор, изополя, мозаики, отчёты. Инструменты сервера читают данные из ЛИРЫ
и передают модулю массивы. Выбран за воспроизводимость и тестируемость при одном вызове
для агента.

## Consequences

- Новые библиотеки: `matplotlib` (изополя и мозаики), `ezdxf` (запись DXF, на этапе 8
  и чтение); библиотека для Word/PDF выбирается в начале этапа 6.
- Правила счёта прогиба записаны в [продукте](../PRODUCT.md) и проверяются модульными
  тестами на балочной плите, плите на колоннах и консоли.
- Модуль не импортирует COM и адаптеры; граница проверяется тестами без ЛИРЫ.
