# 0004 — Сборка моделей из DXF и Revit через САПФИР, после пробы

- Date: 2026-11-03
- Status: accepted
- Approved by: owner

## Context

Владелец хочет получать модель этажа из DXF (слои: контур плиты, отверстия, стены,
пилоны, колонны, нагрузки), модели из аналитической модели Revit и отверстия в плитах
существующих моделей. Главная трудность — сетка конечных элементов: узлы плиты должны
лечь на линии стен и в точки колонн, геометрия у владельца часто косая. Генератор сетки
ЛИРЫ в API 2024 недоступен (только в окне), удалить элемент через API 2024 нельзя.

В библиотеке типов САПФИРа 2024 ([выгрузка](../research/typelib/Sapfir-2024R2.txt))
есть импорт DXF с сопоставлением «слой → тип объекта» (`AutoDlgImportDxf`),
`ImportRevitModel`, `AddLoadCombinationBySaf` и запуск команд меню (`RunCommand`);
описаний методов нет.

## Options

### САПФИР через его API — chosen, после пробы

- Advantages: «родная» сетка ЛИРЫ-САПФИРа, как при ручной работе; конструкции остаются
  объектами (стена, плита), поэтому отверстия и Revit решаются тем же путём.
- Limitations: API не описан; не проверено, строит ли САПФИР сетку и передаёт ли модель в
  ЛИРУ без окон. Если команды открывают диалоги — хрупкое управление окнами.
  Ручные правки в ЛИРЕ после передачи из САПФИРа при повторной передаче теряются.
- Cost and effort: проба 1–2 дня, затем средние.
- Changing it later: средне — чтение DXF и нагрузки остаются, меняется построение схемы.

### Свой генератор сетки (gmsh) — запасной

- Advantages: произвольная геометрия, «вшивает» линии стен и точки колонн в сетку плиты;
  не зависит от САПФИРа.
- Limitations: крупная зависимость с лицензией GPL — совместимость с MIT проекта
  проверить перед выбором; качество сетки проверять на планах владельца; Revit и
  отверстия этим путём не решаются.
- Cost and effort: высокие.
- Changing it later: средне.

### Своя ортогональная сетка

- Advantages: самый простой путь, без новых крупных библиотек.
- Limitations: только геометрия в ортогональных осях; у владельца косые и криволинейные
  стены встречаются часто — отклонён.

## Decision

Этап 8 начинается с пробы САПФИРа: DXF по слоям → объекты → расчётная схема → ЛИРА, и
аналитика Revit → САПФИР → схема. Если проба удастся, сборка моделей, отверстия и Revit
идут через САПФИР. Если нет — запасной путь gmsh для DXF, с отдельным решением владельца;
Revit и отверстия тогда обсуждаются заново. Этап 8 — последний во второй версии.

## Consequences

- Новая часть сервера — адаптер САПФИРа (COM `Sapfir.Application.2024.0`) в COM-потоке;
  её место в схеме определится по итогам пробы.
- Модели этажа: стены и колонны на высоту этажа с защемлением внизу, пилоны оболочками;
  нагрузки на торцы стен — «нагрузки на фрагмент» ЛИРЫ (если фрагмент задаётся через API,
  этап 7).
