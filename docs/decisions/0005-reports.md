# 0005 — Отчёты Word/PDF — python-docx и PDF через установленный Word

- Date: 2026-11-03
- Status: accepted; изменено 2026-11-03 (см. «Изменение»)
- Approved by: owner

## Context

Этап 6 выдаёт отчёты по плитам: сводная таблица и по каждой плите картинка, наибольший
прогиб, пролёт, допустимый прогиб и вывод; так же — мозаики армирования
([продукт](../PRODUCT.md), раздел «Вторая версия»). Инженер хочет и Word (поправить
текст, вставить в пояснительную записку), и PDF (отправить, распечатать). Решение
[0003](0003-postprocessing.md) оставило выбор библиотеки на начало этапа.

## Options

### python-docx, PDF сохраняет установленный Word — chosen

- Advantages: отчёт собирается один раз в `.docx` (python-docx — живая библиотека на
  чистом Python, без внешних программ); PDF выглядит ровно как Word, потому что его
  печатает сам Word (`ExportAsFixedFormat` через COM; pywin32 уже в стеке); у инженеров
  с ЛИРОЙ Word обычно есть.
- Limitations: без Word на компьютере получается только `.docx` и понятное сообщение;
  Word через COM тратит секунды на запуск и изредка может показать своё окно.
- Cost and effort: низкие — один писатель отчёта и короткий адаптер Word.
- Changing it later: легко — добавить второй писатель PDF (fpdf2) для компьютеров без
  Word, около дня работы.

### python-docx и fpdf2 — два независимых писателя

- Advantages: PDF без Word; fpdf2 — чистый Python, кириллица через шрифт Windows.
- Limitations: вдвое больше кода отчёта; Word и PDF выглядят по-разному.
- Cost and effort: средние.
- Changing it later: легко.

### Только Word (python-docx)

- Advantages: проще всего.
- Limitations: PDF инженер сохраняет из Word сам; потолок — нет автоматического PDF.
- Cost and effort: самые низкие.
- Changing it later: легко — любой из путей выше.

## Decision

Отчёт пишет python-docx в `.docx`; PDF из него сохраняет установленный Word через COM.
Выбрано владельцем за одинаковый вид Word и PDF при одном писателе отчёта.

Владелец также решил (2026-11-03): допустимый прогиб по СП 20.13330 (табл. Д.1, п. 2а —
плиты перекрытий, открытые для обзора) по умолчанию — для помещений высотой до 6 м
(значения в скобках); агент может выбрать вариант для помещений выше 6 м.

## Изменение 2026-11-03: PDF без Word, если Word не может

На компьютере владельца Word 2019 работает в «режиме ограниченной функциональности»
(сбой активации) и при открытии документа показывает вопрос «Word не является
программой по умолчанию…»: скрытый Word ждёт ответа и не сохраняет PDF. Владелец
решил: **PDF делает Word, если он работает, иначе — fpdf2** (небольшая библиотека на
чистом Python, кириллица шрифтом Windows Arial или DejaVu из matplotlib). Сервер
запускает свой скрытый Word, следит за его окнами; если Word показал окно или не
ответил вовремя, сервер останавливает этот экземпляр (только его) и пишет PDF сам, а в
ответе называет причину (`pdf_by`). До перезапуска сервера Word больше не
спрашивается. Плата — второй писатель отчёта (`postprocessing/report.py`: `to_docx` и
`to_pdf` по одному содержанию) и чуть другой вид PDF без Word.

## Consequences

- Новые зависимости: `python-docx`, `fpdf2` (с изменения 2026-11-03); вместе с ними
  этапа 6 — `matplotlib`, `ezdxf`, `numpy` (решение [0003](0003-postprocessing.md)).
- Сохранение PDF через Word живёт в адаптере `adapters/word.py`, а не в модуле
  постобработки: модуль по-прежнему не импортирует COM.
- Word запускается отдельным невидимым экземпляром (`DispatchEx`) и закрывается после
  сохранения; документы инженера, открытые в Word, не трогаются.
